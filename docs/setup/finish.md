# 仕上げの設定

[← 配布キットのトップに戻る](../../README.md) ／ [← 2. LINE 側の準備](line.md)

セットアップツールが最後に表示した **6つの項目**を片付けます。
**ここをやらないと、動いているように見えて動きません。**

**所要時間**：約15分
**必要なもの**：セットアップツールが表示した画面（まだ閉じていなければそのまま）

---

## 🔴 いちばん先に：API Key を保存してください

完了画面の一番下に **API Key** が表示されています。

> **この値は再表示できません。**

これは**管理画面にログインするための鍵**です。控え忘れると管理画面に入れなくなります。
パスワード管理アプリか、紙に控えてください。

✅ 保存しましたか？ では先に進みます。

---

## 完了画面に表示された5つの URL

このあと使います。ターミナルを閉じてしまった場合は、下の「[URL を忘れたら](#recover)」を見てください。

| # | 何の URL か | 形 |
|---|---|---|
| A | Webhook URL | `https://〇〇.〇〇.workers.dev/webhook` |
| B | Callback URL | `https://〇〇.〇〇.workers.dev/auth/callback` |
| C | LIFF エンドポイント URL | `https://〇〇.〇〇.workers.dev?liffId=△△△` |
| D | 友だち追加 URL | `https://〇〇.〇〇.workers.dev/auth/line?ref=setup` |
| E | 管理画面 | `https://〇〇.pages.dev` |

> 💡 **手で入力せず、必ずコピーしてください。** 1文字違うだけで動きません。
> 特に **C は末尾の `?liffId=△△△` まで含めて**コピーします。

---

## Step 1：LINE の応答設定を変える

自動応答が有効なままだと、システムの返信とぶつかります。

👉 **[LINE Official Account Manager を開く](https://manager.line.biz/)**

```
アカウントを選択 → 右上の歯車アイコン（設定） → 応答設定
```

**4つとも、この通りに設定してください。**

| 項目 | 設定 |
|---|---|
| チャット | **オフ** |
| あいさつメッセージ | **オフ** |
| Webhook | **オン** |
| 応答メッセージ | **オフ** |

✅ **終わったら**：このページに戻ってきてください。

---

## Step 2：Webhook URL を設定する

LINE からのメッセージを、あなたのシステムに届けるための設定です。

```
同じ画面で → サイドメニューの「Messaging API」
```

**Webhook URL** の欄に **A の URL** を貼り付けて、**保存**を押します。

そのあと、**「Webhookの利用」を ON** にしてください。

✅ **終わったら**：このページに戻ってきてください。

> ⚠️ **「Webhookの利用」の ON を忘れやすいです。** URL を貼っただけでは届きません。

---

## Step 3：LINE ログインチャネルの設定（3つ）

👉 **[LINE Developers Console を開く](https://developers.line.biz/console/)**

プロバイダーを選び、**LINE ログインチャネル**（[2. LINE 側の準備](line.md) の Step 4 で作ったもの）を開きます。

### 3-a. 公式アカウントとリンクする

**「リンクされたLINE公式アカウント」** で、あなたの公式アカウントを選びます。

### 3-b. 友だち追加オプションを確認する

**「友だち追加オプション」** が **`On (Aggressive)`** になっているか確認します。

> 準備のときに設定済みのはずですが、既定値（`On (Normal)`）に戻っていないか見てください。

### 3-c. Callback URL を登録する 🔴 忘れやすい

```
「LINEログイン設定」タブを開く
→ 「ウェブアプリでLINEログインを利用する」を ON
→ 「Callback URL」に B の URL を貼り付け
```

> 🔴 **この設定を飛ばすと、あとで原因が分からない壊れ方をします。**
>
> - スマホからの友だち追加は LIFF 経由なので、**この設定が無くても動いてしまいます**
> - しかし **PC から QR コードを読むと `Invalid redirect_uri` で無言で失敗**します
>
> 「スマホでは動くのに PC だと動かない」という状態になり、原因にたどり着けません。
> **必ず登録してください。**

✅ **終わったら**：このページに戻ってきてください。

---

## Step 4：LIFF エンドポイント URL を本物に変える

準備のときに **`https://example.com`** という仮の値を入れました。それを本物に置き換えます。

```
LINE Developers Console → LINE ログインチャネル → 「LIFF」タブ
→ 作成した LIFF アプリを開く
→ エンドポイント URL を C の URL に変更
```

> 🔴 **`?liffId=△△△` の部分まで必ず含めてください。**
> ここを落とすと動きません。完了画面の URL をそのままコピーするのが確実です。

> 💡 あわせて、**LIFF アプリが「公開済み」**になっているかも確認してください。

✅ **終わったら**：このページに戻ってきてください。

---

## Step 5：動作確認（友だち追加）

いよいよ確認です。

1. **D の友だち追加 URL** を、自分のスマホで開きます
2. 友だち追加します
3. **E の管理画面 URL** をブラウザで開き、**API Key** でログインします
4. 友だち一覧に**自分の名前とプロフィール画像**が出れば成功です 🎉

さらに、LINE でそのアカウントにメッセージを送ってみてください。管理画面の個別チャットに会話が表示され、**管理画面から返信もできます。**

### うまくいかないときの見どころ

| 症状 | 見るところ |
|---|---|
| 友だち追加しても管理画面に出ない | Step 2 の **「Webhookの利用」が ON か** |
| PC から QR を読むと何も起きない | Step 3-c の **Callback URL** が登録されているか |
| 友だち追加の画面が真っ白 | Step 4 の **`?liffId=` が付いているか**／LIFF が**公開済み**か |
| 自動返信が二重に来る | Step 1 の **応答メッセージがオフ**になっているか |

---

## Step 6：友だち追加の配り方

お客様に友だち追加してもらうときは、**QR コードの直リンクではなく、D の友だち追加 URL を配ってください。**

この URL を経由しないと、システム側で友だちを認識できません。

## URL を忘れたら

ターミナルを閉じてしまっても、URL は下記のファイルに残っています。

```
~/.line-harness/.line-harness-config.json
```

`workerUrl`（A〜D の元になる URL）と `adminUrl`（E）が入っています。

> ⚠️ **API Key はこのファイルに入っていません。** 完了画面でしか見られない値です。
> 控え忘れた場合は、そのまま進めずにご連絡ください。

## 完了です 🎉

サーバー代0円で動く LINE 公式アカウント用 CRM が、あなたの資産として稼働しています。

### 運用にあたって

**費用**：Cloudflare の無料枠は、中小事業者の通常利用ならまず超えません。
ただし LINE 公式アカウント側は、メッセージ通数によって別途費用がかかります（無料プランは月200通まで）。

**2つ目を作りたくなったら**：Cloudflare の無料枠には
**cron トリガーが1アカウント5本まで**という上限があります。
このシステムは1つにつき2本使うため、**同じアカウントに置けるのは2つまで**です。

**アップデート**：新しいバージョンが出たときは、次のコマンドで更新できます。

```
npx create-line-harness@latest update
```
