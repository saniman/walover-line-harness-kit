# セットアップツールの実行

[← 配布キットのトップに戻る](../../README.md) ／ [← 2. LINE 側の準備](line.md)

準備した値を使って、システムを Cloudflare に構築します。**ここは自動です。**

**所要時間**：約15〜25分（ほとんどは待ち時間）
**必要なもの**：[2. LINE 側の準備](line.md) でそろえた5つの値

---

## ⚠️ この工程だけ、ターミナルを使います

> **この作業は Claude にやってもらうことができません。**
>
> セットアップツールは「キーボードから直接入力される」ことを前提に作られており、
> Claude 経由で実行すると、最初の質問が出た時点でエラーで止まります。
> **あなた自身がターミナルを開いて実行してください。**

身構えなくて大丈夫です。**やることは「コマンドを1行貼り付けて、質問に答える」だけ**です。

---

## Step 1：ターミナルを開く

**macOS の場合**

1. `⌘（command）` + `スペース` を押す
2. `ターミナル` と入力する
3. Enter を押す

黒い（または白い）画面が開きます。これがターミナルです。

> 💡 **Windows をお使いの方へ**
> 本キットの動作確認は macOS で行っています。Windows での手順は未検証です。
> Windows で進めたい場合は、着手する前にご相談ください。

---

## Step 2：Node.js を確認する

このツールは Node.js という土台の上で動きます。**バージョンと種類**を確認します。

ターミナルに、次の行をそのまま貼り付けて Enter を押してください。

```
node -p "process.version + ' / ' + process.arch"
```

### 出た結果の見方

| 出たもの | 判定 |
|---|---|
| `v20` 以上 かつ `arm64` | ✅ Apple Silicon の Mac なら OK |
| `v20` 以上 かつ `x64` | ⚠️ **Intel Mac なら OK。Apple Silicon なら要対処**（下記） |
| `v18` など 20 未満 | ❌ [nodejs.org](https://nodejs.org/) の **LTS 版**を入れ直してください |
| `command not found` | ❌ Node.js が未インストールです。[nodejs.org](https://nodejs.org/) の **LTS 版**を入れてください |

### 🔴 Apple Silicon なのに `x64` と出た場合

**そのまま進めると、インストールの途中でエラーになって止まります。**

自分の Mac を確認するには、`  アップルメニュー → このMacについて → チップ` を見てください。
`Apple M1` `M2` `M3` `M4` などと書かれていれば Apple Silicon です。

その場合は、[nodejs.org](https://nodejs.org/) から **LTS 版を入れ直して**ください。
ダウンロードページで **Apple Silicon（ARM64）向け**を選ぶのが確実です。

> 💡 なぜこうなるか：Apple Silicon の Mac に Intel 用の Node.js が入っていると、
> 途中で使われる部品が互換モードで動かず、`SIGILL` というエラーで停止します。
> WALOVER の検証でも実際に発生しました。

---

## Step 3：ツールを実行する

準備した5つの値を手元に置いてから始めてください。**途中で取りに戻ると面倒です。**

ターミナルに次の行を貼り付けて、Enter を押します。

```
npx create-line-harness@latest setup
```

> ⚠️ **`--help` を付けないでください。**
> このツールにヘルプ機能は無く、付けても**そのままセットアップが始まってしまいます**。

### 最初に少し待ちます

「ダウンロード中」「依存関係インストール中」と表示され、**1〜3分ほど無反応に見えます。**
数百MBのダウンロードが走っているので、そのまま待ってください。

---

## Step 4：質問に答える

順番に聞かれます。**答える内容は次のとおりです。**

| 順 | 聞かれること | 答えるもの |
|---|---|---|
| 1 | R2 の有効化が完了したら Enter | そのまま **Enter**（[1. Cloudflare の準備](cloudflare.md) が済んでいれば OK） |
| 2 | プロジェクト名 | 英小文字・数字・ハイフン（例：`my-line-bot`）。そのまま Enter で既定値も可 |
| 3 | Channel ID（数字） | **①** |
| 4 | チャネルシークレット | **②** |
| 5 | チャネルアクセストークン（長期） | **③** |
| 6 | チャネル ID（数字） | **④** ← ①ではありません |
| 7 | LIFF ID | **⑤** |
| 8 | workers.dev サブドメイン名 | 好きな名前（**世界中で早い者勝ち**。取られていたら別の名前を求められます） |
| 9 | MCP 設定を追加しますか？ | どちらでも可（`No` で構いません） |

> 🔐 **②と③を入力すると、画面にそのまま表示されます。** 伏字にはなりません。
> 人に見られる場所では作業しないでください。**この画面のスクリーンショットも送らないでください。**

> 🔴 **6番で①を入れてしまう間違いが起きやすいです。**「④＝ログイン用」のメモを確認してください。

### Cloudflare へのログインを求められたら

ブラウザが開いてログインを求められることがあります。画面の指示に従って許可してください。
終わるとターミナルに戻ります。

---

## Step 5：完了を待つ

答え終わると、あとは自動です。順に進みます。

```
D1 データベース作成 → テーブル作成 → R2 バケット作成
→ Worker のビルド・デプロイ → 管理画面のデプロイ
```

**5〜15分ほどかかります。** 進行中はクルクル回る表示が続きます。

✅ **「セットアップ完了！」**と出て、①〜⑥の指示が並んだ画面が出れば成功です。

---

## 🔴 完了画面が出たら、まず API Key を控えてください

画面の一番下に **API Key** が表示されています。**再表示できません。**
管理画面にログインするための鍵なので、閉じる前に必ず保存してください。

---

## 途中でエラーが出たら

**やり直しは軽いです。** 進んだところまで記録されているので、
直したあとに**同じコマンドをもう一度**実行すれば、続きから再開できます。

```
npx create-line-harness@latest setup
```

`前回の途中から再開します` と表示されたら、**`continue`** を選んでください。
D1 や R2 は作り直されず、**LINE の5つの値も入力し直しになりません。**

### よくあるエラー

| メッセージに含まれる語 | 意味と対処 |
|---|---|
| `SIGILL` / `esbuild` | Node.js が CPU と合っていません。[Step 2](#step-2node-js-を確認する) に戻ってください |
| `Please enable R2` / `10042` | R2 が有効化されていません。[1. Cloudflare の準備](cloudflare.md) の Step 3 へ |
| `cron triggers` / `10072` | 下記を参照してください |

### `cron triggers` のエラーが出た場合

Cloudflare の無料枠は **cron が1アカウント5本まで**で、このシステムは**1つにつき2本**使います。
すでに他で Workers を使っていると、上限に当たることがあります。

👉 **[Workers の一覧を開く](https://dash.cloudflare.com/?to=/:account/workers/overview)**

使っていない Worker の Cron Triggers を削除して空きを作り、もう一度実行してください。

> 同じアカウントに置けるのは**2つまで**です。3つ目は必ずこのエラーになります。

---

## ⚠️ 途中で止まったまま放置しないでください

エラーで止まると、`~/.line-harness/.line-harness-setup.json` というファイルに
**チャネルシークレットとアクセストークンが、そのまま読める状態で残ります。**

最後まで完走すれば、このファイルは自動で消えます。
**中断したままにせず、必ず完了させてください。**

> 🔐 質問の際に、**このファイルは送らないでください。**
