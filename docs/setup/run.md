# セットアップツールの実行

[← 配布キットのトップに戻る](../../README.md) ／ [← 2. LINE 側の準備](line.md)

準備した値を使って、システムを Cloudflare に構築します。**ここは自動です。**

**所要時間**：約15〜25分（ほとんどは待ち時間）
**必要なもの**：[2. LINE 側の準備](line.md) でそろえた5つの値

---

## ターミナルで打つのは、1行だけです

**入力はブラウザの画面で行います。** ターミナルは、その画面を開くために1行打つだけです。

黒い画面に値を打ち込む必要はありません。**入力欄の隣に「どこで取るか」の手順と
実際の画面写真が並ぶ**ので、迷ったらその場で確認できます。

---

## Step 1：ターミナルを開く

**macOS の場合**

1. `⌘（command）` + `スペース` を押す
2. `ターミナル` と入力する
3. Enter を押す

黒い（または白い）画面が開きます。これがターミナルです。

**Windows の場合**

1. スタートボタンを右クリック
2. **ターミナル**（または **PowerShell**）を選ぶ

> 💡 **Windows をお使いの方へ**
> macOS では実機で確認済み、Windows は自動テストで確認しています。
> ただし **Cloudflare アカウントを複数お持ちの場合**、アカウントを選ぶ画面で
> 「画面が進まなくなりました」と出ることがあります。
> そのときは画面の案内にしたがって手で入力してください。

---

## Step 2：Node.js を確認する

このツールは Node.js という土台の上で動きます。**バージョンと種類**を確認します。

ターミナルに、次の行をそのまま貼り付けて Enter を押してください。

```
node -p "process.version + ' / ' + process.arch"
```

### 出た結果の見方

| 出たもの | 判定 |
|---|---|
| `v20` 以上 かつ `arm64` | ✅ Apple Silicon の Mac なら OK |
| `v20` 以上 かつ `x64` | ⚠️ **Intel Mac なら OK。Apple Silicon なら要対処**（下記） |
| `v18` など 20 未満 | ❌ [nodejs.org](https://nodejs.org/) の **LTS 版**を入れ直してください |
| `command not found` | ❌ Node.js が未インストールです。[nodejs.org](https://nodejs.org/) の **LTS 版**を入れてください |

### 🔴 Apple Silicon なのに `x64` と出た場合

**そのまま進めると、インストールの途中でエラーになって止まります。**

自分の Mac を確認するには、`  アップルメニュー → このMacについて → チップ` を見てください。
`Apple M1` `M2` `M3` `M4` などと書かれていれば Apple Silicon です。

その場合は、[nodejs.org](https://nodejs.org/) から **LTS 版を入れ直して**ください。
ダウンロードページで **Apple Silicon（ARM64）向け**を選ぶのが確実です。

> 💡 なぜこうなるか：Apple Silicon の Mac に Intel 用の Node.js が入っていると、
> 途中で使われる部品が互換モードで動かず、`SIGILL` というエラーで停止します。
> WALOVER の検証でも実際に発生しました。

---

## Step 3：セットアップ画面を開く

ターミナルに、次の行をそのまま貼り付けて Enter を押してください。

```
npx walover-line-harness-gui@0.1.0
```

初回は必要なものの取得に**1〜2分**かかります。次のように表示されたら成功です。

```
  LINE Harness セットアップ画面を起動しました

    http://127.0.0.1:4321
```

ブラウザが自動で開きます。開かないときは、表示された URL をコピーして開いてください。

> 💡 **この画面は、あなたのパソコンの中だけで動いています。**
> 入力した値がインターネットに送られることはありません。

> ⚠️ **ターミナルは閉じないでください。** 閉じると画面も止まります。
> 作業が全部終わったら、ターミナルで `Ctrl` + `C` を押して終了します。

---

## Step 4：フォームに入力する

[2. LINE 側の準備](line.md) でそろえた値を入れていきます。

各欄の下にある **「どこで取るか」** を開くと、手順・注意点・作業画面へのリンク・
**実際の画面写真**が出ます。取りに戻るときはそこから開いてください。

> 🔴 **①と④の取り違えに注意してください。**
> 「Channel ID（Messaging API チャネル）」と「チャネル ID（LINE Login チャネル）」は
> **別のチャネル**のものです。同じ値を入れると、画面が止めて教えてくれます。

**チャネルシークレット**と**チャネルアクセストークン**は伏字で表示されます。
確認したいときは右の「表示」を押してください。

入力し終えたら **「入力内容を保存する」**、続いて **「セットアップを開始する」** を押します。

---

## Step 5：進むのを見守る

黒い枠にツールの出力が流れます。**ここに文字を打つ必要はありません。**
操作が必要なときは、その上にボタンが出ます。**キーボードの Enter は使いません。**

途中で2回ほど、あなたの操作を待つ場面があります。

| 出るもの | やること |
|---|---|
| **R2 の有効化は終わりましたか？** | [1. Cloudflare の準備](cloudflare.md) で済ませてあれば「完了しました」を押す |
| Cloudflare アカウントの選択 | 使うアカウントを選ぶ（1つしか無ければ出ません） |

**5〜15分ほどかかります。** ほとんどは待ち時間です。

### Cloudflare へのログインを求められたら

ブラウザに Cloudflare の認証画面が出ることがあります。ログインして許可してください。
すでに `wrangler` でログイン済みなら、この画面は出ません。

---

## Step 6：完了画面から値を控える

終わると、黒い枠が畳まれ、**仕上げの手作業6件が一覧で表示されます。**
貼り付ける値には**コピーボタン**が付いているので、手で書き写す必要はありません。

### 🔴 API Key を先に保存してください

一番下に **API Key** があります。**この値は二度と表示できません。**
「表示」で中身を確認し、「コピー」でコピーして、
**パスワード管理アプリなど安全な場所に保存**してください。

管理画面にログインするための鍵です。

---

## 途中でエラーが出たら

**やり直しは軽いです。** 進んだところまで記録されているので、
直したあとに**同じコマンドをもう一度**実行すれば、続きから再開できます。

```
npx walover-line-harness-gui@0.1.0
```

`前回のリソースをどう扱いますか？` と聞かれたら、**「リセットせず、現在のアカウントで続行する」**
を選んでください。D1 や R2 は作り直されず、**LINE の5つの値も入力し直しになりません。**

### よくあるエラー

| メッセージに含まれる語 | 意味と対処 |
|---|---|
| `SIGILL` / `esbuild` | Node.js が CPU と合っていません。[Step 2](#step-2node-js-を確認する) に戻ってください |
| `Please enable R2` / `10042` | R2 が有効化されていません。[1. Cloudflare の準備](cloudflare.md) の Step 3 へ |
| `cron triggers` / `10072` | 下記を参照してください |
| `擬似端末を用意できません` | macOS ならターミナルで `xcode-select --install` を実行してください |
| `知らないプロンプトが出たので自動応答を止めました` | ツールが対応していない質問が出ています。連絡してください |

### `cron triggers` のエラーが出た場合

Cloudflare の無料枠は **cron が1アカウント5本まで**で、このシステムは**1つにつき2本**使います。
すでに他で Workers を使っていると、上限に当たることがあります。

👉 **[Workers の一覧を開く](https://dash.cloudflare.com/?to=/:account/workers/overview)**

使っていない Worker の Cron Triggers を削除して空きを作り、もう一度実行してください。

> 同じアカウントに置けるのは**2つまで**です。3つ目は必ずこのエラーになります。

---

## ⚠️ 途中で止まったまま放置しないでください

エラーで止まると、`~/.line-harness/.line-harness-setup.json` というファイルに
**チャネルシークレットとアクセストークンが、そのまま読める状態で残ります。**

最後まで完走すれば、このファイルは自動で消えます。
**中断したままにせず、必ず完了させてください。**

残っている場合は、次にセットアップ画面を開いたときに警告が出ます。

> 🔐 質問の際に、**このファイルは送らないでください。**

- 画面に出ているメッセージ

> 🔐 **スクリーンショットを送るときの注意**
> セットアップ画面ではシークレットが伏字になりますが、
> **Cloudflare のアカウント ID やメールアドレス**が写ることがあります。
> 送る前に必ず確認し、写っている部分は隠してください。
